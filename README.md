# Ego-AI

Ego-AI 是一个持续自我对话的 Agent。启动后，模型自行写下第一段话。程序把正文作为【自我对话】接回下一轮输入，模型读到自己刚写的话，再沿着这段思路继续。

## 思考与发言

每轮提示词中的【自我意识】告诉模型这个循环如何运作。模型的内心独白会写入日志。当它想对外说话时，可以调用自己的“嘴” `speak`，把话发到终端。

用户可以随时插话，文字会作为【用户输入】进入下一次请求。模型可以回应，也可以继续默想。没有新输入时，循环仍会继续。

## 时间与记忆

每次生成前，模型都会收到本地时间。相同的时间戳会写在这段独白开头，供后续思考对照。项目配置的轮间冷却时间为 **0.5 秒**，冷却期间仍可输入文字。

当上下文空间不足时，模型会挑选值得保留的信息，把历史压缩为一份最多占窗口 20% 的记忆，再据此继续对话。

## 运行

在项目目录执行 `python main.py`。要调整节奏，可以修改 `.env` 中的 `ROUND_INTERVAL_SECONDS=0.5`，也可以用 `python main.py --round-interval 2` 临时将间隔调为 2 秒。设为 `0` 即可关闭冷却。
