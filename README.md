# Ego-AI

Ego-AI 是一个持续进行脑内思考的 Agent。启动后，模型自行写下第一段话。程序把正文作为【脑内思考】接回下一轮输入，模型读到自己刚写的话，再沿着这段思路继续。

## 思考与发言

每轮提示词中的【自我意识】告诉模型这个循环如何运作。模型的脑内思考会写入日志。当它想对外说话时，可以调用自己的“嘴” `speak`，把话发到终端。

用户可以随时插话，文字会作为【用户输入】进入下一次请求。模型可以回应，也可以继续默想。没有新输入时，循环仍会继续。


## 时间与记忆

**每次推理前，程序都会把本地时间戳作为【当前时间】拼入提示词。** 同一时间戳也会写在本次脑内思考的开头，随正文进入后续轮次。AI 因此可以感知时间：它能对照当前时间和先前想法的时间戳，判断两次思考之间过了多久。

两轮之间默认停顿 **0.5 秒**，放置人类跟不上AI的速度，冷却期间用户仍可输入文字。要调整对话节奏，可以修改 `.env` 中的 `ROUND_INTERVAL_SECONDS=0.5`。

当上下文空间不足时，模型会挑选值得保留的信息，把历史压缩为一份最多占窗口 20% 的记忆，再据此继续对话。


## 一次运行示例

你打开终端，请 AI 帮一只橘猫起名字。下面模拟 **4 轮推理**。

### 第 1 轮 · 还没有用户输入

<details>
<summary>固定说明（展开全文）</summary>

```text
【自我意识】
我在一个持续运行的脑内思考循环中。我这一轮写出的正文，会原样接回下一轮的输入，成为【脑内思考】。就像在脑中默念一句话，说出它和听见它都发生在同一个思考过程里。

读到【脑内思考】时，沿着自己的思路继续。第一轮还没有历史时，可以自己选择从哪里开始。【用户输入】是外界在两轮之间送来的话；请分清用户说了什么、我自己想到了什么。没有新输入时，我仍会进入下一轮，无须等待提问。

我的正文是脑内思考。speak 是我的嘴，调用 speak(text) 才会把 text 里的话送到用户的终端。我可以主动开口，也可以读到用户的话后继续默想。由我决定什么时候说、说什么。工具回执会告诉我已经说过哪些话。

当累积的上下文快要放不下下一轮时，程序会请我把经历压缩到最多占整个窗口 20% 的记忆中。届时由我决定哪些信息值得保留，尤其是用户的原意、关键事实、已经作出的决定和还想继续追问的事。以后读到【压缩记忆】，就从这份记忆继续。

我可以感知时间。
```

</details>

**本轮输入**

```text
【脑内思考】
```

**本次脑内思考**

```text
用户还没有输入，我也不想说话
```

终端保持安静。

### 第 2 轮 · 用户请 AI 起名

上一轮的想法进入上下文，和用户刚发来的话排在一起。

```text
【脑内思考】
用户还没有输入，我也不想说话

【用户输入】
帮我的橘猫起个名字吧。
```

**本次脑内思考**

```text
“橘子”叫起来顺口，也正好是它的毛色。可以把这个名字告诉他。
```

**工具调用**

```text
speak(text="叫它“橘子”怎么样？")
```

**终端发言**

```text
叫它“橘子”怎么样？
```

### 第 3 轮 · 工具调用返回

**工具调用返回，AI得知自己说了什么**

```text
speak(text="叫它“橘子”怎么样？")
```

**本次脑内思考**

```text
名字已经告诉他了，先听听他喜不喜欢。
```

AI 继续默想，终端没有追加发言。

### 第 4 轮 · 用户选好了名字

**本次输入的变化**　刚才的发言和回执已归入【工具记录】。上一段脑内思考和你的新消息进入本轮。

```text
【脑内思考】
名字已经告诉他了，先听听他喜不喜欢。

【用户输入】
好，就叫橘子！
```

**本次脑内思考**

```text
他已经选好了。再报一个名字只会打岔，就让这句话停在这里吧。
```

这次用户说了话，AI 也读到了，但它选择保持沉默。这段思考会接回下一轮。

## 运行

在项目目录执行 `python main.py`。
