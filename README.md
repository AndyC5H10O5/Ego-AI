# Ego-AI

Ego-AI 是一个持续自我对话的 Agent。启动后，模型自行写下第一段话。程序把每轮生成的正文作为【自我对话】接回下一轮输入，模型读到自己刚写的话，再沿着这段思路继续。

每轮提示词都包含【自我意识】，告诉模型这个循环如何运作。用户可以随时插话，提交的文字会作为【用户输入】加入下一次请求。没有新输入时，自我对话也会继续。

模型的正文是内心独白，保存在运行日志中。它可以通过工具调用使用自己的“嘴” `organ/speak.py`，把想说的话发到终端。它既可以主动开口，也可以在读到用户输入后保持沉默。

当上下文窗口爆满时，程序会请模型挑选值得保留的信息，把历史压缩为一份最多占窗口 20% 的记忆，再据此继续对话。

运行：`python main.py`
